# 微信小程序社交功能移除与界面改版设计规格

日期：2026-06-15  
状态：设计已审批  
审批方向：C 的温暖米橙配色 + B 的高效管理员看板

## 1. 改版目标

将现有打卡小程序从包含社区互动的任务制产品，调整为仅支持“管理员管理任务、成员完成个人打卡”的封闭式任务工具。

本次改版必须彻底移除所有用户之间的直接互动与互相浏览能力，同时保留管理员对自己管理任务中成员完成情况的查看权限。

## 2. 角色与权限

### 2.1 成员

成员可以：

- 通过管理员分享链接或邀请码加入任务。
- 查看自己参与的任务及管理员发布的打卡内容。
- 播放任务音频或视频并提交本人打卡心得。
- 查看、筛选和导出本人的打卡记录。
- 查看本人的任务进度、日历和累计完成次数。

成员不可以：

- 查看任何其他成员的昵称、头像、完成记录、心得或动态。
- 查看成员列表、排行榜或整体成员完成情况。
- 评论、点赞、关注、私信或通过其他方式直接互动。
- 发布面向其他成员可见的内容。

### 2.2 管理员

管理员可以：

- 创建和管理任务。
- 发布音频或视频打卡内容。
- 通过分享链接或邀请码邀请成员加入。
- 查看自己管理的任务内成员名单。
- 查看任务内每位成员的完成状态、累计完成次数和对应任务打卡记录。
- 按日期或完成状态筛选成员完成情况。
- 导出自己管理任务的完成数据。
- 移除成员。

管理员不可以：

- 创建社区帖子或面向所有用户发布动态。
- 评论、点赞、关注或私信成员。
- 查看不属于自己管理任务的成员记录。

### 2.3 创建者与管理员关系

- 任务创建者拥有任务解散和管理员角色设置权限。
- 普通管理员拥有发布任务、邀请成员、查看完成情况和移除普通成员权限。
- 角色权限沿用现有任务内角色体系，但所有操作必须受任务归属校验。

## 3. 信息架构

底部导航统一调整为四项：

1. **今天**：成员查看今日待办；管理员同时可看到自己管理任务的简要状态。
2. **计划**：查看全部参与和管理的任务。
3. **记录**：仅展示当前用户本人的打卡记录。
4. **我的**：账号资料、隐私政策、用户协议和设置。

删除底部导航中的“社区”，不再提供排行榜入口。

## 4. 页面设计

### 4.1 今天

视觉方向：

- 米白背景、暖橙主色、浅橙内容区域。
- 标题采用陪伴式表达，例如“今天，完成一件小事”。
- 不展示任何其他成员、排行榜或社交数据。

主要内容：

- 今日剩余打卡数量。
- 继续完成今日打卡的主按钮。
- 正在进行的任务卡片。
- 当前用户本周完成节奏。
- 管理员可额外看到“我管理的任务”摘要，并进入管理控制台。

### 4.2 计划

主要内容：

- 分为“我参与的”和“我管理的”，不展示其他成员信息。
- 提供创建任务和输入邀请码加入任务入口。
- 任务卡展示任务名称、日期范围、本人进度和本人角色。

成员任务详情：

- 任务名称、日期范围、管理员名称。
- 本人的完成进度和任务日历。
- 今日或当前打卡内容。
- “仅本人记录”隐私提示。
- 不显示任务成员数量、成员名单、整体完成率或成员状态。

管理员任务详情 / 管理控制台：

- 整体完成率、成员总数、已完成数、未完成数。
- 成员完成状态列表。
- 按今天、本周或全部范围筛选。
- 发布新打卡内容。
- 分享邀请或复制邀请码。
- 查看成员在本任务中的打卡记录。
- 导出任务完成数据。
- 任务设置、成员管理和任务解散。

### 4.3 打卡提交

主要内容：

- 展示管理员发布的音频或视频。
- 保留“播放后才允许提交”的现有业务规则。
- 提供个人心得输入框。
- 显示明确隐私说明：内容不会向其他成员展示。
- 提交成功后不再生成帖子，只保存个人打卡记录。

### 4.4 记录

主要内容：

- 仅展示当前用户本人的记录。
- 支持按任务、开始日期和结束日期筛选。
- 支持导出本人选中的记录。
- 记录卡只展示任务名称、打卡内容、心得和提交时间。
- 不展示点赞数、评论数、帖子入口或其他用户信息。

### 4.5 我的

主要内容：

- 微信头像和昵称设置。
- 本人参与任务数量、本人累计打卡次数。
- 隐私政策、用户协议和必要设置。
- 不展示个人动态或他人可访问的个人主页。

### 4.6 加入任务

主要内容：

- 展示任务名称和管理员提供的任务说明。
- 成员确认后加入任务。
- 仅收集完成任务管理必需的信息。
- 加入前明确提示：管理员可以查看该任务内的完成状态和打卡记录，其他成员不可查看。

## 5. 视觉规范

### 5.1 色彩

- 页面背景：`#FCFAF6`
- 卡片背景：`#FFFDF9`
- 主色暖橙：`#E98243`
- 渐变辅助橙：`#F2B36D`
- 浅色内容区：`#FBEFE4`
- 分割线：`#F0E7DC`
- 主文字：`#30261E`
- 次要文字：`#988878`
- 成功状态可使用主色或低饱和暖色，不引入社交平台常用的互动红点。

### 5.2 组件

- 卡片使用大圆角和轻阴影。
- 主操作使用圆角胶囊按钮。
- 成员端减少数据密度，突出今日行动。
- 管理员端保持高信息密度，使用统计卡、筛选标签和状态列表。
- 所有成员状态仅在管理员控制台显示。

## 6. 必须删除的前端范围

删除页面：

- `pages/forum`
- `pages/post`
- `pages/rank`

删除或调整入口：

- 从 `app.json` 页面和底部导航中移除社区与排行榜。
- 从自定义底部导航中移除社区入口和中央发布按钮。
- 从任务详情移除社区、排行榜和成员端成员列表。
- 从个人记录移除帖子跳转、点赞数和评论数。
- 从所有页面移除发布帖子、点赞、评论和回复操作。

调整页面：

- `pages/tasks` 改为“今天”。
- `pages/taskboard` 改为“计划”。
- `pages/task` 按成员和管理员角色展示不同信息。
- `pages/item` 改为私密打卡提交页。
- `pages/profile` 拆分为“记录”与“我的”所需内容，或新增独立记录页。
- `pages/join` 增加隐私边界说明。

## 7. 必须删除或收紧的后端范围

删除 API：

- `GET /api/tasks/:id/rank`
- `GET /api/tasks/:id/posts`
- `POST /api/tasks/:id/posts`
- `GET /api/posts/:id`
- `POST /api/posts/:id/comment`
- `POST /api/posts/:id/like`

调整 API：

- `POST /api/items/:id/submit`：停止同步创建 `posts`。
- `GET /api/tasks/:id`：成员响应不得包含成员列表和整体成员数据；管理员响应才可以包含管理所需成员信息。
- `GET /api/tasks/:id/my-records`：只返回本人记录，不返回帖子 ID、点赞数或评论数。
- 新增或调整管理员成员完成情况接口，必须校验调用者是该任务管理员。
- 导出接口区分“本人记录导出”和“管理员任务数据导出”，并执行对应权限校验。

数据处理：

- 停止读取和写入 `posts`、`post_comments`、`post_likes`。
- 社交历史数据不在界面或 API 中暴露。
- 正式删除历史社交数据前应先备份；删除策略在实施计划中明确。

## 8. 隐私与权限约束

- 所有成员记录查询必须绑定当前登录用户 ID。
- 管理员查询成员记录必须同时校验任务 ID、管理员身份和成员归属。
- 成员任务详情 API 不得返回可推断其他成员状态的数据。
- 禁止通过参数替换查看其他任务或其他成员记录。
- 客户端隐藏入口不是权限控制，所有限制必须在服务端执行。
- 隐私政策和用户协议需同步删除社区互动相关描述。

## 9. 核心数据流

### 9.1 成员打卡

1. 成员进入“今天”或“计划”。
2. 成员打开自己参与任务中的打卡内容。
3. 播放音频或视频后，服务端记录已观看状态。
4. 成员填写本人心得并提交。
5. 服务端仅写入 `checkin_records`。
6. 成员可在“记录”中查看本人记录。
7. 对应任务管理员可在管理控制台查看完成状态和该任务记录。

### 9.2 管理员管理

1. 管理员进入管理控制台。
2. 服务端校验管理员属于该任务。
3. 管理员查看成员完成状态或发布打卡内容。
4. 管理员通过筛选和导出完成任务监督。
5. 全流程不产生用户间互动内容。

## 10. 错误处理

- 无任务权限：返回明确的无权限提示，不返回任务数据。
- 成员尝试访问管理员接口：服务端返回 `403`。
- 非本人记录查询：服务端返回 `403` 或 `404`，不泄露记录是否存在。
- 媒体未观看就提交：保留现有校验提示。
- 任务不存在、已解散或邀请失效：加入页显示明确状态。
- 网络或上传失败：保留表单内容并支持重试。

## 11. 测试与验收标准

### 11.1 社交功能删除验收

- 小程序中不存在社区、论坛、帖子、排行榜、点赞、评论、关注和私信入口。
- 打卡提交后不会创建帖子。
- 成员无法查看任何其他成员信息或记录。
- 原社交 API 均不可调用。

### 11.2 成员权限验收

- 成员只能查询本人记录。
- 成员任务详情不返回成员列表和整体完成数据。
- 修改请求参数无法查询其他成员记录。

### 11.3 管理员权限验收

- 管理员只能查看自己管理任务中的成员状态和记录。
- 管理员可以发布任务、邀请成员和导出任务数据。
- 非管理员调用管理接口返回 `403`。

### 11.4 界面验收

- 成员端使用已审批的温暖米橙视觉。
- 管理员控制台采用高信息密度统计与成员状态列表。
- 四项底部导航为“今天、计划、记录、我的”。
- 页面中隐私边界提示清晰可见。
- 所有原有中文文本编码正常显示。

## 12. 实施边界

- 本设计覆盖小程序前端、Node.js 服务端、接口权限、数据暴露和协议文本。
- 不引入聊天、通知、成员提醒或其他可能形成用户直接互动的新功能。
- 不在本次改版中重构与目标无关的部署和存储架构。
- 实施阶段必须保留用户当前未提交的工作区修改，并在修改前核对现有差异。
