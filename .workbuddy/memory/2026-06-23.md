# 2026-06-23 工作日志

## 音视频无法播放问题排查

### 现象
- 杰哥反馈：小程序上传音频/视频后无法播放
- 真机 + 开发者工具都测试过，downloadFile 合法域名已配置
- 播放时弹"视频加载失败"toast，但控制台无具体报错

### 诊断过程
用 curl 测试线上服务器各端点：
- `POST /api/login` → 401 + JSON `{"err":"invalid code"}` ✅ 路由存在
- `POST /api/upload` → 401（auth 拦截）✅ 路由存在
- `GET /api/tasks` → 401（auth 拦截）✅ 路由存在
- `GET /media/123.mp4` → **404 + HTML "Cannot GET /media/123.mp4"** ❌ 路由不存在

### 根本原因
**本地代码与线上部署版本不一致**
- 本地 `server/index.js` 第 41 行有 `app.get('/media/:key', ...)` 路由（配合 COS 存储）
- 线上跑的旧版本没有这个路由
- 上传走 `/api/upload` 成功，storage.put 返回 `/media/xxx` 存入数据库
- 播放访问 `/media/xxx` → 线上无此路由 → 返回 404 HTML
- 小程序 video/InnerAudioContext 收到 HTML 不是视频流 → 加载失败（但无网络层错误，所以无报错）

### 解决方案
**重新部署 server 代码到微信云托管**即可，无需改代码。
